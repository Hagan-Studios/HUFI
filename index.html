Why HUFI?

  • Minimal 13-Byte Header: Fixed Little-Endian binary header (HUFI signature, W, H, channels) allows sub-millisecond header parsing without reading the full payload.
  • Predictive Byte Delta Filtering: Employs horizontal sub-filtering to maximize Zlib Deflate entropy reduction.
  • Lossless RGB Fidelity: Preserves 100% pixel accuracy with zero visual compression artifacts.
  • Native Desktop Viewer: Lightweight standalone GUI app supporting pan, zoom, dark mode, and automatic OS file association.
